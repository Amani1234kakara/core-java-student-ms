# core-java-student-ms
A Student Management System developed using Core Java, demonstrating OOP concepts, Encapsulation, Constructors, and Object Creation. This project helps manage student information efficiently.

**Features:**
- Student information management
- Create and initialize student objects
- Store Student ID, Name, Age, Course, and Marks
- Display student details
- Multiple student object creation

**Technical Details:**
- Language: Java 21
- Core Java
- Object-Oriented Programming (OOP)
- Encapsulation
- Constructors
- Instance Variables
- Getters
- `this` Keyword

**IDE:** IntelliJ IDEA

**Build Type:** Console-based Java Application
